01 — Tentang Saya

Siapa saya?

Sedikit cerita tentang latar belakang dan perjalanan saya di dunia teknologi.

Halo! Nama saya Muhammad Akbar Pradana, siswa jurusan Keterampilan Desain Web dan duduk di kelas XI F yang berada di MAN 2 Kota Madiun. Saya tertarik di dunia pengembangan web dan desain antarmuka.

Saya mulai belajar coding dari HTML & CSS sederhana, lalu berkembang ke JavaScript, Python, dan UI Design. Saya percaya kode yang baik bukan hanya yang berjalan, tapi juga yang indah dan mudah dimengerti.

Di luar coding, saya suka eksplorasi desain visual, mendengarkan musik, membuat musik, dan terus mencoba hal-hal baru di dunia teknologi.
